# Publications

Ce répertoire est public. Déposez uniquement des contenus autorisés pour diffusion publique.

Depuis l’espace de gestion du site, préparez un événement et téléchargez son ZIP. Extrayez-le, puis déposez le dossier entier ici avec Add file → Upload files et validez Commit changes. Ne déposez pas le ZIP lui-même.

Chaque dossier comporte publication.json et ses supports. Le workflow indexe les métadonnées, légendes et textes renseignés. Les dossiers à l’état draft sont exclus du site, mais restent visibles dans le dépôt public et son historique.

Voir le guide à la racine du dépôt pour les limites, les corrections et les retraits.
